通过 HTTPS 接入 SOSKS5 商品、库存与订单服务。此页面是接口接入说明模板；请以服务端实际路由、字段和鉴权策略为准。所有分销商密钥必须仅保存在服务端，不要写进浏览器代码或公开仓库。

快速开始

API 基础地址（请确认部署环境）：

https://api.lynli.me/api/shop

示例请求使用公开商品查询路由。若服务端要求分销商 Token，请在服务器端添加请求头。

curl -sS 'https://api.lynli.me/api/shop/products' \
  -H 'Accept: application/json'

GET /products · 商品列表

读取可售商品、套餐规格和标价。建议使用服务端返回的商品 ID 创建订单，不要由客户端自行计算最终应付金额。

GET /api/shop/products
Accept: application/json

// 示例响应结构（字段以实际 API 为准）
{
  "products": [
    {
      "id": "plan_188g_30d",
      "name": "188G / 30天",
      "price": 0,
      "currency": "CNY",
      "stock": 0
    }
  ]
}

GET /inventory · 库存查询

查询可售库存。建议对分销商接口配置限流、权限范围和审计日志；不要向公开客户端返回账号密码或完整未售库存明文。

GET /api/shop/inventory
Accept: application/json

POST /orders · 创建订单

服务端应重新校验商品、价格、库存、幂等键和支付渠道。成功后返回订单号与支付跳转地址。

POST /api/shop/orders
Content-Type: application/json

{
  "product_id": "plan_188g_30d",
  "email": "buyer@example.com",
  "payment_method": "alipay"
}

// payment_method 示例：alipay / wechat / usdt_trc20
示例只描述预期接口形状，不代表已验证的真实响应。请以已部署后端的 OpenAPI/实际返回为准。

鉴权与错误码

公开读取接口可按服务端策略免鉴权；分销商私有接口应使用独立 Token，并在服务端校验权限、配额和有效期。

Authorization: Bearer YOUR_PARTNER_TOKEN
Accept: application/json

常见状态码：
200  请求成功
400  参数错误
401  Token 缺失或无效
403  权限不足
404  商品或订单不存在
409  库存不足 / 幂等冲突
429  请求过于频繁
500  服务端异常

支付回调与自动发号

支付网关回调应由后端验签，核对金额、币种、商户订单号及交易号，并通过幂等事务更新订单。只有确认支付成功后才触发发号；重复回调不能重复发货。

不要相信浏览器跳转结果作为付款凭证。USDT TRC20 需在服务端核验链上交易、目标地址、金额、确认数与订单绑定关系。

POST /ai/chat · AI 客服

网站客服将问题发送至后端 AI 接口。智谱 API Key 等密钥只能放在服务端环境变量中，设置超时、限流和输入输出审查。

POST /api/shop/ai/chat
Content-Type: application/json

{
  "message": "188G 套餐如何配置节点？",
  "context": "套餐购买与节点配置"
}
SOSKS5 Developer Portal · 请勿将分销商 Token 或支付密钥提交到公开前端。
